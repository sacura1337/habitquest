# HabitQuest — УП.08, задание 3

Адаптивный интерфейс трекера привычек с геймификацией на **React + Vite + CSS**. Визуальная система продолжает макеты задания 2: фиолетовый акцент, светлая/тёмная тема, карточки статистики и адаптивная боковая навигация.

## Реализованные экраны
- Главная панель: XP, серия дней, ежедневные привычки, недельный график и челлендж.
- Привычки: список, отметка выполнения и добавление привычки.
- Статистика: ключевые метрики, недельный график и список привычек.
- Достижения: сетка открытых и закрытых наград.
- Профиль: данные пользователя и краткая сводка прогресса.
- Настройки: переключение темы и демо-настройки.
- Мобильное меню и адаптивные состояния для небольших экранов.

## Запуск
Нужен Node.js LTS. Откройте эту папку в VS Code и в терминале выполните:

```bash
npm install
npm run dev
```

Откройте адрес, который покажет Vite (обычно `http://localhost:5173`).

## Проверка production-сборки

```bash
npm run build
```

Результат появится в `dist/`.

## Скриншоты
Папка `docs/screenshots/` содержит визуальные материалы и вырезки из дизайн-борда задания 2. Они помечены как макеты/референсы, а не как реальные скриншоты работающего приложения. После запуска сделайте реальные скриншоты браузера и добавьте их в эту папку.

## Ограничения текущего этапа
Это frontend-прототип: привычки и XP работают в демонстрационном состоянии React и не сохраняются в БД. Авторизация, backend/API и реальная база данных относятся к следующим этапам практики. Перед сдачей нужно проверить сборку и фактическую работу в браузере.
