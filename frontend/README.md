# HabitQuest — клиентская часть (задания 3–7)

Интерфейс трекера привычек с геймификацией на **React 18 + Vite**. Приложение получает
данные с бэкенда FastAPI по REST API: демонстрационных массивов в коде нет, всё, что видит
пользователь, приходит из базы данных.

**Опубликованная версия:** https://sacura1337.github.io/habitquest/

Публикация выполняется автоматически: при изменениях в папке `frontend` в ветке `main`
запускается GitHub Actions, собирает проект и выкладывает его на GitHub Pages.
Настройка — в файле `.github/workflows/deploy-frontend.yml`.

## Реализованные экраны

- **Стартовая страница** — витрина приложения с якорными разделами «О проекте»,
  «Возможности», «Как это работает» и подвалом с контактами.
- **Вход и регистрация** — формы с проверкой данных в браузере и на сервере.
- **Главная панель** — показатели, уровень и полоса опыта, слайдер привычек из базы,
  график выполнения, список привычек и последнее достижение.
- **Привычки** — переключение между таблицей и каталогом, поиск, три фильтра,
  сортировка по столбцам, постраничная навигация, создание, изменение, удаление
  и отметка выполнения.
- **Одна привычка** — динамический маршрут `/app/habits/:id` со статистикой
  и историей выполнения за период.
- **Статистика** — сводка за день, неделю и месяц, график по дням, разбивка
  по категориям, общая история выполнения с сортировкой.
- **Достижения** — сетка наград с прогрессом и фильтром по состоянию.
- **Профиль** — загрузка аватара, изменение имени, сводная статистика.
- **Настройки** — выбор темы, адрес API, сведения о проекте.
- **Страница 404** — для несуществующих адресов.

## Запуск

Нужен Node.js 20 или новее.

```bash
npm install
copy .env.example .env.local   # Linux / macOS: cp .env.example .env.local
npm run dev
```

Откройте адрес, который покажет Vite в терминале (по умолчанию `http://127.0.0.1:5173`).

Перед запуском убедитесь, что бэкенд работает: адрес указывается в `.env.local`
переменной `VITE_API_URL` (по умолчанию `http://127.0.0.1:8000`).

## Проверка production-сборки

```bash
npm run build
```

Результат появится в `dist/`.

## Переменные окружения

| Переменная | Назначение | Значение по умолчанию |
| --- | --- | --- |
| `VITE_API_URL` | адрес REST API бэкенда | `http://127.0.0.1:8000` |
| `VITE_BASE` | базовый путь сборки для публикации в подкаталоге | `/` |

## Комментарий к реализации

Код намеренно написан на JavaScript (JSX), без TypeScript: так проект остаётся
проще для защиты и не требует отдельной настройки компилятора типов.
Слайдер реализован самостоятельно, без сторонней библиотеки, — задание допускает
и свой вариант, а поведение при этом полностью под контролем.
Единственная добавленная зависимость — `react-router-dom`, она нужна для
маршрутизации и динамических маршрутов.
